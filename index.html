02 / Featured research

Hybrid learning for scalable HJ reachability

An ongoing MARS Lab project that treats a decomposed Hamilton–Jacobi solution as a useful learning prior, rather than an answer to copy.

Ongoing · 2026–present

Using approximate structure without inheriting its mistakes.

Grid-based Hamilton–Jacobi solvers provide strong safety information but become impractical as a system’s dimension grows. This project uses a cheap, dense decomposed value function to initialize and guide a neural approximation, while keeping the HJ PDE residual as the final correctness signal.

Its gap-aware guidance reduces reliance on the teacher precisely where a shared control budget can make decomposition inaccurate. The framework is studied across 4D, 6D, and 10D dynamical systems, connecting value-function accuracy to closed-loop control.

Manuscript in preparation. Public project materials will be added after release.
